По моему мнению, нормальная альтернатива устаревшему во всем AutoClicker OP, и другим вариантам. 

Автокликер для Windows: интервалы, разброс, умный клик по цвету, макросы, профили, оверлей, горячие клавиши.

Возможности

- Интервал клика (ч / мин / сек / мс), разброс ± мс
- Кнопка мыши, одинарный / двойной / тройной клик
- Повтор N раз или до остановки, лимит по времени
- Позиция: текущая или точка X/Y, разброс px, плавный ход (Безье)
- Макросы: запись, таблица шагов, экспорт / импорт
- Профили настроек
- Мини-оверлей, пауза при смене окна
- Язык RU / EN, тема, шрифт.
